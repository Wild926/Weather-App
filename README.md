Weather App

A simple and responsive Weather App that fetches real-time weather data using the OpenWeather API
. Displays key weather details, including temperature, humidity, wind speed, and current conditions in a clean and user-friendly interface.

Live Demo -

Here is a link to view the app live, copy and paste into a new browser - https://wild926.github.io/Weather-App/

Features - 

  • Real-time weather updates via OpenWeather API.

Displays:

  • Temperature

  • Humidity

  • Wind speed

  • Weather condition icon

  • Responsive design for mobile and desktop

  • Built with HTML, CSS, and JavaScript

Technologies Used

  • HTML5

  • CSS3

  • Vanilla JavaScript

  • OpenWeather API

How to Use Locally

Clone this repo:

git clone https://github.com/Wild926/Weather-App.git

  1, Open the folder in your editor.

  2, Generate an API key from OpenWeather.

  3, Add your API key to the script where required.

  4, Open index.html in your browser.

All the code for this project can be viewed here - https://github.com/Wild926/Weather-App
